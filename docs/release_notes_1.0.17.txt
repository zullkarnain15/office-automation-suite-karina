OAS-K 1.0.17
8 October 2026

Release production untuk OAS-K core database schema 4 dan database analytics
Attendance & OT schema 9.

Tampilan Attendance & OT dan Fingerprint Monitoring:
- Attendance & OT menggunakan tema default yang seragam dengan modul lain;
  tidak lagi menggunakan tampilan Chalkboard.
- Font pixel dipakai secara terbatas pada header tabel dan tombol; teks
  dashboard, tab, dan isi tabel menggunakan font standar agar terbaca jelas.
- Warna teks Dashboard dan Data Terlambat dikontraskan kembali agar tidak
  putih di atas latar terang. Detail data memakai garis dan zebra striping
  ringan agar baris lebih mudah dibaca.
- Fingerprint Monitoring mengikuti tema default, dengan indikator online
  hijau yang terlihat jelas, teks status perangkat netral, dan progress
  percentage yang tidak terpotong.
- Tab History pada Fingerprint Monitoring menyediakan tombol kalender untuk
  tanggal From dan To.
- Database Maintenance Attendance & OT dipindahkan ke Settings > Storage &
  Database agar toolbar utama lebih ringkas.

Application shell:
- Status database pada footer kini disinkronkan setelah startup, System Health,
  validasi, refresh, inisialisasi, dan repair storage.
- Status database tidak lagi kembali ke "Belum diperiksa" saat berpindah
  halaman atau saat pesan aplikasi berubah menjadi Ready.

Kompatibilitas database:
- Update package menerima OAS-K 1.0.15 dan 1.0.16 sebagai versi sumber.
- Core OAS-K production schema 4 tetap schema 4; tidak ada migrasi core.
- Database Attendance & OT production schema 9 tetap schema 9; tidak ada
  migrasi analytics.
- Database dan data production existing dipertahankan dan diverifikasi melalui
  backup pre-update serta post-update health check.

Paket update hanya berisi aplikasi dan metadata update. Data Root, database,
konfigurasi aktif, log, output, backup, dan recorder profiles tidak disertakan.
