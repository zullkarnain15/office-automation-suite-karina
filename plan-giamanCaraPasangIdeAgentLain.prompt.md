1. Buka Extensions di VS Code:
   - Tekan Ctrl+Shift+X
   - Atau klik ikon kotak di sidebar kiri

2. Cari extension agent yang kamu inginkan:
   - Misal GitHub Copilot, ChatGPT, CodeGPT, atau extension AI lain

3. Klik Install

4. Setelah terpasang:
   - Buka Command Palette (Ctrl+Shift+P)
   - Ketik nama extension / agent, misalnya Copilot: Open Chat

Jika maksudmu adalah agent Copilot kustom di workspace:
- Letakkan file .agent.md atau AGENTS.md di root proyek
- Gunakan perintah Copilot untuk memilih agent dari workspace

Catatan: install extension baru hanya bisa lewat VS Code Marketplace / Extensions view.
