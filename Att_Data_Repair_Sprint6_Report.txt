12. Global Period Resolution
Default checkbox state comes from att_data_repair_settings.use_global_period.
When enabled, resolved period comes from General Settings period_start and period_end.

The source workbook is not used as a period fallback.

13. Local Period Resolution
When global period is disabled, local Period Start and Period End from the UI request are used.
Local period requires both dates.
start > end is blocked with "Tanggal mulai tidak boleh lebih besar dari tanggal selesai."
Local period is not written to General Settings or Att Data Repair settings.

14. Global Output Resolution
Default checkbox state comes from att_data_repair_settings.use_global_output.
When enabled, resolved output root comes from General Settings output_root.
Output field is readonly and Browse is disabled through _apply_global_state.
Missing global output is blocked with a user-facing message.

15. Local Output Resolution
When global output is disabled, local Output Folder from the UI request is used.
Output Browse uses folder picker.
The UI passes only the output root to the engine; the engine/job manager creates Utilities\Att_Data_Repair\YYYY-MM-DD_XX.
Local output is not written to SQLite.

27. Status Mapping
SUCCESS maps to successful UI state.
PARTIAL_SUCCESS maps to "Berhasil dengan peringatan" and prompts the user to check Excel Report.

FAILED maps to failed UI state with user-facing error summary.
CANCELLED maps to canceled UI state when cancellation occurs before engine start.
